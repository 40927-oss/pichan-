การพิสูจน์ทฤษฎีบทพีทาโกรัส

การพิสูจน์ทฤษฎีบทพีทาโกรัส ถ้าต้องการ ทฤษฎีและการพิสูจน์ทฤษฎีบทพีทาโกรัส สำหรับเขียนส่งครู สามารถเขียนได้ดังนี้ ทฤษฎีบทพีทาโกรัส ทฤษฎีบท: ในสามเหลี่ยมมุมฉาก กำลังสองของความยาวด้านตรงข้ามมุมฉาก เท่ากับผลบวกของกำลังสองของความยาวด้านประกอบมุมฉากทั้งสองด้าน กำหนดให้ a และ b เป็นด้านประกอบมุมฉาก และ c เป็นด้านตรงข้ามมุมฉาก จะได้ว่า a 2 + b 2 = c 2 การพิสูจน์ สร้างสี่เหลี่ยมจัตุรัสขนาด ( a + b ) × ( a + b ) และนำสามเหลี่ยมมุมฉากที่เหมือนกัน 4 รูปมาจัดเรียงไว้ภายใน โดยเหลือพื้นที่ตรงกลางเป็นสี่เหลี่ยมจัตุรัสที่มีด้านยาว c พื้นที่สี่เหลี่ยมจัตุรัสใหญ่คือ ( a + b ) 2 พื้นที่สามเหลี่ยมมุมฉาก 1 รูปคือ 1 2 a b ดังนั้นพื้นที่สามเหลี่ยมทั้ง 4 รูปคือ 4 ( 1 2 a b ) = 2 a b และพื้นที่สี่เหลี่ยมตรงกลางคือ c 2 จึงได้ว่า ( a + b ) 2 = 2 a b + c 2 กระจายพจน์ a 2 + 2 a b + b 2 = 2 a b + c 2 ตัด 2 a b ทั้งสองข้าง จะได้ a 2 + b 2 = c 2 ดังนั้นจึงพิสูจน์ได้ว่า ทฤษฎีบทพีทาโกรัสเป็นจริง ✅
